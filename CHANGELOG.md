# Changelog

## 1.0.0

- Change locale settings to BCP 47 tags. Reject `en-UK` and `none`.
- Add Unicode and CJK text handling, locale formatting and typography.
- Split the image, processing, spelling and formatting packages.
- Add the adacovex complexity and SBOM make targets.
- Collapse the three entry points into one CLI implementation.
- Harden core counts, image subprocess clean-up and config caching.
- Add Python 3.14 support and a test matrix from 3.10 to 3.14.
